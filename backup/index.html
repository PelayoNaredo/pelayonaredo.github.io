Puntos de interés turísticos

La página utiliza datos abiertos del Ayuntamiento de Gijón para mostrar puntos de interés turísticos como alojamientos, monumentos y museos un mapa interactivo. Este trabajo destaca por la integración de APIs, diseño de interfaces intuitivas y gestión dinámica de datos. El proposito de la página es ser incorporada en el futuro por el Ayuntamiento en su pagina web oficial para tener una forma de mostrar información relevante para visitantes y ciudadanos.

Aplicación Web Gijón Playas

El apartado diseñado para la web gijon.es/playas ofrece información en tiempo real sobre las condiciones de las playas de Gijón. Se destacan los niveles de seguridad mediante banderas en las escaleras de acceso, indicando si las condiciones del mar son aptas para el baño. Adicionalmente, incluye datos sobre la temperatura del aire, horarios de pleamar y bajamar, velocidad del viento y el índice de radiación ultravioleta, ayudando a los usuarios a planificar su visita de manera informada.


La interfaz también ofrece datos sobre la calidad sanitaria del agua en diferentes puntos, confirmando si es apta para el baño. Para asegurar la seguridad de los visitantes, se muestran los horarios de los servicios de salvamento. Proporcionando toda la información relevante de forma clara y accesible, destacando su optimización para su integración en la web a través de un iframe.

Proyecto App Horarios
(WIP)

En este proyecto personal, estoy desarrollando una aplicación con el objetivo de gestionar diversos aspectos clave de un negocio. En ella se incluyen módulos como turnos, ventas, inventarios y gestión de empleados. A futuro, planeo incorporar un sistema de gestión de turnos por IA, que será desarrollado desde el backend, así como un chat empresarial para mejorar la comunicación interna.
El enfoque principal de la aplicación es permitir que los administradores o gerentes puedan controlar todas las áreas operativas, mientras que los empleados reciben únicamente la información relevante para el desempeño de sus tareas diarias.
El stack tecnológico utilizado en este proyecto es React Native, NodeJS, Express y MongoDB (MERN), seleccionados por su escalabilidad, flexibilidad y facilidad de uso.
Además, junto a el se han utilizado tecnologias backend para establecer seguridad de acceso como JSON Web Tokens, CORS y bcrypt.
